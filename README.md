# Inventory App (Jetpack Compose + Room)

This project is an Android Inventory app built with:

- Kotlin
- Jetpack Compose
- Room (SQLite)
- Navigation Compose
- ViewModel + StateFlow

## Features

- View item list
- Add new item
- Open item details
- Sell one unit from details
- Edit existing item
- Delete item

## Run locally

```powershell
./gradlew.bat :app:assembleDebug
```

## Run unit tests

```powershell
./gradlew.bat :app:testDebugUnitTest
```
